# Security

Please report vulnerabilities privately, not in a public issue:

- GitHub: [report a vulnerability](https://github.com/openparley/openparley/security/advisories/new) (private advisory), or
- email support@openparley.dev with "Security" in the subject.

Include what you found, how to reproduce it, and what an attacker could do with it. You'll get a reply within a few working days. Please give us a reasonable time to fix the issue before you disclose it.

In scope: this repository (the overlay, Sync, Cloud) and the services at openparley.dev and its subdomains. Out of scope: denial of service, volume-based attacks, spam, and findings that need a compromised device or browser.

Only the latest release on `master` gets security fixes.
